### This directory contains the scripts and the reference Af293 for custom fitting the _A. fumigatus_ reference genome to SigProfiler ### 


- Due to the size, the GFF file could not be uploaded. Instead, the GFF file can be downloaded directly using the NCBI API command below:

https://api.ncbi.nlm.nih.gov/datasets/v2/genome/accession/GCF_000002655.1/download?include_annotation_type=GENOME_FASTA&include_annotation_type=GENOME_GFF

  Or manually (Download --> Annotation features (GFF)) via this adress:
  
  https://www.ncbi.nlm.nih.gov/datasets/genome/GCF_000002655.1/
